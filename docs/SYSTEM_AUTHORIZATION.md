# 系统授权

“设置 → 授权”提供修改系统设置、悬浮窗和创建 VPN 的手动入口，以及内置 Android 9 授权组件的保存入口。当前组件为 **11**，包名 `com.android.vpndialogs`；主应用正式版和测试版统一为 `com.preface.carplay`。

- **修改系统设置／悬浮窗**：优先系统页面；缺失时使用兼容且就绪的授权组件，返回后读取实际状态。
- **创建 VPN**：只在用户点击时准备并请求系统确认，仅授权，不启动连接。无线不申请 VPN；USB 启动按需准备 [NCM＋本地 TUN](USB_VPN_RESTORE_0.2.20.md)。页面渲染和恢复不调用 `VpnService.prepare()`。
- **保存授权 APK**：保存 `Preface-Android9-Authorization.apk` 到公共 Download 根目录，由用户通过文件管理器手动安装。同名旧文件经校验后覆盖，相同内容不重复写入或自动打开目录。
- **打开保存目录**：独立于保存按钮，优先系统下载入口；系统受理请求不等于目录已实际显示。

组件已有六项系统授权也支持符合条件的其他应用；VPN 必须由目标应用自行发起，不能代选包名。安装来源、使用情况访问和无障碍管理只在组件标准 Settings 入口提供，主应用不增加这些项目。

蓝牙音乐代理只接受采用仓库原证书的 `com.preface.carplay`，并校验同用户、会话、所选已配对 iPhone、通话和实际连接状态。旧组件不支持新包名，需重新保存并手动升级至 11。组件没有桌面图标；原厂／未知同名组件保留，平台不匹配时不导出。旧独立 UID 组件需仅手动卸载该旧补丁后重装，不卸载 CarPlay 或清数据。完整边界见 [授权组件](ANDROID9_AUTHORIZATION_COMPONENTS.md)。

授权拒绝、组件缺失或桥接失败均明确提示并停止自动重试，不自动授予权限或修改 VPN app-op。用户反馈过旧版本授权恢复正常，不能据此认定当前包名的全部授权及 USB 通信已通过实车验收。
