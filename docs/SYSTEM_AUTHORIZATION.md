# 系统授权

“设置 → 授权”提供修改系统设置、悬浮窗和创建 VPN 的手动入口，并可保存主 APK 内置的 Android 9 授权组件。已交付主应用 0.1.1 / 95、组件 7；兼容性、迁移、签名和构建核验统一见 [授权组件说明](ANDROID9_AUTHORIZATION_COMPONENTS.md)。

后续源码 **0.1.1 / 97、组件 8（未打包）**：组件现有六项授权均可用于符合条件的其他应用；修改系统设置和悬浮窗的标准系统入口可先选择应用，VPN 必须由目标应用自己发起系统确认。每次确认复核身份和策略，不增加 CarPlay 主授权页项目，不转授组件自身系统权限；蓝牙音乐代理仍只服务已核对签名的两个 CarPlay 包。

## 操作

- **修改系统设置**：用 Settings.System.canWrite() 显示本应用状态；打开授权页供用户确认，返回后刷新。手动车机热点自动开启还取决于系统接口，临时热点不需要此权限。
- **悬浮窗**：显示系统状态，优先原生设置页，缺失时使用兼容且就绪的补丁；打开页面不等于授权完成。
- **创建 VPN**：只在用户点击时调用 VpnService.prepare()；需要时显示系统确认，成功返回后由主应用复核。取消、组件缺失或接口失败明确提示，不启动连接。
- **保存授权 APK／打开保存目录**：按钮始终同行可用，保存到公共 Download 根目录，由文件管理器手动安装。相同文件不重复保存或自动跳目录，原厂／未知组件和不匹配平台保留。

页面渲染、设置搜索和恢复不调用 VpnService.prepare()；该接口可能改变当前准备的 VPN 应用，不能作为无副作用的状态查询。页面只显示最近一次手动检查结果。USB 启动及该次授权返回允许调用准备接口；无线不申请 VPN、不创建 TUN。

USB 使用 [NCM＋本应用专用本地 VPN/TUN](USB_VPN_RESTORE_0.2.20.md)，只路由 fe80::/64，不连接远程服务器。授权拒绝、组件缺失或桥接失败时停止自动重试，不伪造授权或通过 ADB 修改 VPN app-op。

组件 7 没有桌面入口。旧独立 UID 补丁需先保存新版，仅手动卸载旧补丁后重装，保留 CarPlay。安装来源、使用情况访问、无障碍管理只在补丁标准入口提供；主应用授权页不增加这些项目。用户已取消通知使用权和电池优化授权。

## 验证限制

用户已反馈授权功能恢复正常，没有逐项权限和完整 USB 通信的新验证。构建 94 的主包签名、内置组件和模拟器覆盖安装已核对，未运行完整 CI。测试图不能替代实车截图，后台启动、目录实际显示和 USB/TUN 建链仍分别验证。

接口语义：[修改系统设置](https://developer.android.com/reference/android/provider/Settings#ACTION_MANAGE_WRITE_SETTINGS)、[VpnService.prepare](https://developer.android.com/reference/android/net/VpnService#prepare(android.content.Context))。
