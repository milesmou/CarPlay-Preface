# 星瑞 E02 桌面导航集成

2026-10-15 按用户要求，已从主应用移除“仪表盘上的 CarPlay 地图（实验性）”。

应用不再申请独立仪表／桌面地图 Stream 111，不再提供地图悬浮卡片或 `com.shihab.diplay.action.EMBED_MAP` 地图共享服务，相关设置、开关及自动申请使用情况访问权限的路径一并移除。旧保存设置不会重新启用功能；旧备份中的已移除地图开关不再导入。正常 CarPlay 主屏中的地图显示继续使用主视频流。

## 保留的桌面导航小部件

支持标准 Android 小部件的桌面，可以添加“CarPlay 导航”小部件。它显示转向箭头、距离、道路、到达时间、剩余里程／时间和当前歌曲信息；它不是实时地图画面，不需要独立地图流。

点击小部件可以打开 CarPlay，未连接时打开应用。导航和歌曲信息通过现有 iAP2 数据通道更新，最多每秒刷新一次。原车桌面是否允许添加第三方小部件，仍取决于其自身实现，不将本次移除描述为已验证桌面显示能力。

## 示例与历史说明

上游的 `home`／`maphost` 示例保留在源码中作为历史参考；其中实时地图嵌入协议在当前主应用中已移除，不能再用这些示例请求地图。本次没有为星瑞新增其他仪表或第三方地图适配分支。
