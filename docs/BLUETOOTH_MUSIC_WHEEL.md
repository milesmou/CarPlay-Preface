# 音频方案

“设置 → 音频”的第一个卡片提供两个选项，更改在下次连接生效，不中断当前会话。

| 选项 | 行为 |
| --- | --- |
| CarPlay 音频（默认） | 音乐通过 CarPlay 播放；保留媒体方控与导航混音，音量由车机系统控制。 |
| 蓝牙音频 | iPhone 声音走原车蓝牙，CarPlay 保留画面和触摸；媒体键由原车处理，不重复转发。 |

CarPlay 模式通过授权组件 11 为当前会话所选 iPhone 申请 A2DP 临时断开租约，确认真实断开后再申请音乐焦点。退出或取消时仅有界恢复本租约实际请求断开的连接，不操作配对、HFP／SCO、其他手机或蓝牙总开关。旧组件不支持新的统一包名，需手动更新。

媒体／导航流默认 3／12，用户已保存的路由和焦点关闭选择优先。导航实际发声时只将本应用音乐压至 30%，通话／Siri 发声时静音本应用音乐，结束后按有效焦点恢复。已移除按播放状态切换音量控制及旧导航音量联动选项，旧配置不能恢复这些功能。

蓝牙模式不公告或接收 CarPlay 音频，不创建音乐 MediaSession、不申请音乐焦点；导航、电话和 Siri 的声音去向取决于手机与车机路由。Siri、电话键保留各自的通话与会话检查。音频模式保存在 `car_bluetooth_audio`，当前会话继续使用连接时的选择。
