# 音频方案

当前源码保留授权组件 10 的所选 iPhone A2DP 会话租约与确认断开后的音乐焦点，按用户最新要求[移除独立媒体助手](MEDIA_ASSISTANT_REMOVAL_2026-10-20.md)，此次未重新打包。最近构建 100 的 IHU353G / 系统 169 [日志](CONNECTION_REPORT_2026-10-20_BUILD100_AUDIO.md)已确认无线和 USB 的实际 A2DP 断开及退出恢复，一次无线方向盘 NEXT 成功；媒体助手自己的准入仍被拒绝。

此前测试包 0.1.1 / 99 已构建，内置授权组件 9，包含下述音量及 Siri 修正；已覆盖安装到 API 34 模拟器 emulator-5558 并保留数据，[构建核验](ANDROID9_AUTHORIZATION_COMPONENTS.md)。随后新包实车日志确认 CarPlay 音频仍有自动暂停、切歌转蓝牙：原车蓝牙发送 PAUSE，原厂下一曲让蓝牙夺回焦点，媒体中心授权仍被拒绝，详见 [构建 99 音频报告](CONNECTION_REPORT_2026-10-20_BUILD99_AUDIO.md)。本轮仅分析，未修改运行代码或打包。音频方案位于“设置 → 音频”的第一个卡片，不再显示实验性标记。保留两个互斥选项：

| 选项 | 行为 |
| --- | --- |
| CarPlay 音频（默认） | 使用 CarPlay 音频和媒体方控，音量由原车调节。 |
| 蓝牙音频 | iPhone 音频走原车蓝牙，CarPlay 保留画面与触摸，媒体方控由原车处理。 |

移除“按播放状态调整媒体／导航音量”及第三种模式，删除前台窗口与后台按键服务的音量流切换路径。旧 diplay_navigation_wheel.enabled 保存值不再读取、迁移或恢复；它不能重新启用该功能，也不会单独触发后台服务恢复。媒体／导航默认流 3／12、独立路由设置，以及实际语音触发的 30% 导航混音不受影响。

## 保存与会话

两种模式只复用 car_bluetooth_audio，保留用户已保存的蓝牙选择；未开启时为 CarPlay 音频。保存后调用 markReconnectNeeded()，在下次连接生效，当前控制器、焦点和方控继续按现有会话运行，不擅自断开。

蓝牙模式关闭整套 CarPlay 音频协商，不只静音音乐：不公告音频格式、不接管主音频资源，拒绝普通及缓冲音频 SETUP，保留屏幕、触摸与数据。导航、电话和 Siri 的声音去向取决于手机与车机路由，异常时切回 CarPlay 音频。

蓝牙会话不创建音乐 MediaSession、不申请音乐焦点、不重复转发媒体键或申请原厂播放音源；保留同手机、通话、取消代际和真实播放状态检查。直接蓝牙连接接口不可用时可使用内置授权组件的限定代理，细节见 [蓝牙与方控修正](BLUETOOTH_WHEEL_RECOVERY_2026-10-19.md)。系统受理不等于已经连接，原厂自动暂停与切歌跳页仍需实车确认。

2026-10-20 的构建 97 车机日志确认，原车蓝牙进程在自身 `audioFocus=0` 时发送 AVRCP 暂停。构建 98 源码新增一次原车蓝牙 `MediaBrowser` 的标准 `prepare()`，由原车进程准备其焦点；主应用仍不持有音乐焦点、不发送播放或切歌命令、不创建媒体会话。仅所选 iPhone 为唯一已连接且仍配对的 A2DP 手机、无通话时执行，回调前复核；失败不循环重试，取消使迟到回调失效，不在切换收音机后重复争夺。该请求本身不等于焦点获准或已经播放，当次源码阶段尚未打包；随后构建 98 的用户反馈见下文。证据与 CarPlay 音频的厂商准入阻塞见 [完整报告](CONNECTION_REPORT_2026-10-20_BUILD97.md)。

2026-10-20 随后用户使用构建 98 确认蓝牙和 CarPlay 两种方式切歌均正常，但音量键只调整通话音量。应用／车机日志已定位到通话结束时恢复旧系统模式被拒绝，导致本应用通信模式残留；源码改为释放自身请求，尚未打包或实车复测。该用户反馈不证明媒体中心准入成功，详见 [构建 98 音量报告](CONNECTION_REPORT_2026-10-20_BUILD98_VOLUME.md)。

用户继续反馈 Siri 无法方控唤醒。源码已将默认语音广播接收器接入两种音频模式，并允许可见 CarPlay 在音乐尚无焦点时接受语音请求；保留通话、绑定和会话检查。蓝牙模式仍不持有音乐焦点、不重复转发媒体键；默认语音路径无需无障碍授权，82 项定向测试通过，尚未打包或实车验证，见 [Siri 方控报告](PREFACE_SIRI_WHEEL_2026-10-20.md)。
