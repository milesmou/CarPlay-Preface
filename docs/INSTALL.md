# 安装与连接

本分支面向吉利星瑞 E02。提供的车机固件为 Android 9／API 28；固件接口和实车待验证项目见 [固件资料索引](PREFACE_FIRMWARE_REFERENCE.md)。

## 安装

1. 在车辆停放时安装车机端 APK，应用名称为 CarPlay。
2. 当前源码构建方法见 [构建说明](BUILD.md)。测试包和 Release 默认使用仓库 `signing/` 中的同一证书；测试包包名为 `com.shihab.diplay.hudtest`，Release 为 `com.shihab.diplay`。
3. 已发布的 [0.1.0 预览版](https://github.com/milesmou/CarPlay-Preface/releases/tag/v0.1.0) 早于认证资源导入，使用它时需另行配置认证资料。当前源码构建已默认包含所导入的两项认证资源，详见 [来源与配置](CARPLAY_AUTH_RESOURCES.md)。
4. 按所用功能授予蓝牙、定位、麦克风和通知权限。车机上的其他投屏应用可能占用同一连接或音频资源，连接前关闭。
5. 首次设置共四步：连接方式、iPhone、自动连接与位置共享、完成。无需选择车型或语言。

ADB 在线时可覆盖安装并保留数据：

```sh
adb -s <设备序列号> install -r mobile/build/outputs/apk/debug/mobile-debug.apk
```

相同包名的旧应用若使用不同证书，覆盖安装会失败；构建流程会报告错误，不自动卸载或清除数据。

## 有线连接

使用支持数据传输的 USB 端口和线缆，选择有线连接并按车机提示授权 USB。固件声明 USB host／accessory 能力，但各物理端口是否可连接 iPhone 仍需实车核对。

## 无线连接

推荐选择首位的“临时热点”：应用通过 Android `WifiManager.startLocalOnlyHotspot()` 创建供 CarPlay 使用的本地网络，名称、密码和频段由系统分配，并通过蓝牙传给 iPhone。无需预先填写热点名称和密码。Android 9 需授予定位权限并打开系统定位；已有车载热点可能与临时热点冲突，遇到不兼容模式提示时先关闭原车热点。临时热点不提供互联网，停止连接会释放本应用的预约；不强制关闭其他应用持有的热点。

也可选择“车载热点”，保存热点名称与密码，在原车设置中开启热点；若可用，可选择 5 GHz。iPhone 保持 Wi-Fi 和蓝牙开启并与车机配对，再点击连接。已保存的连接方式继续优先，调整推荐顺序不会覆盖已有选择。

若自动加入失败，先手动加入应用显示的热点，记录是否能建立 CarPlay 连接。Wi-Fi Direct 和现有 Wi-Fi／同一局域网方式已移除，旧设置自动迁移为临时热点。车机自动开启原车热点依赖现场可用接口、权限及已授权 ADB，默认关闭，不代表已完成 E02 实车验证。

## 音频与方控

默认媒体音频流为 3，导航音频流为 12；两项应用输出比例初始均为 50%，已有手动设置优先。更改音频路由后按页面提示重新连接。

星瑞方控通过原厂标准媒体广播处理切歌及播放／暂停，原厂音量键继续由车机处理。Siri 支持标准语音键及按键学习，原厂私有语音键的完整接入仍待验证；不使用其他车型的 OneOS 输入服务。

## 问题反馈

在“诊断”中保存报告，注明星瑞年款、E02 固件、应用版本、iPhone／iOS 版本、连接方式、复现步骤和发生时间。报告应先自行查看再上传，不包含热点密码或配对密钥。请向 [当前仓库](https://github.com/milesmou/CarPlay-Preface/issues) 反馈。
