# 安装与连接

本分支面向 **2023 款吉利星瑞 1.5T（E02）车机，无飞屏功能**。提供的车机固件为 Android 9／API 28；固件接口和实车待验证项目见 [固件资料索引](PREFACE_FIRMWARE_REFERENCE.md)。

## 安装

1. 在车辆停放时安装车机端 APK，应用名称为 CarPlay。
2. 当前源码构建方法见 [构建说明](BUILD.md)。测试包和 Release 默认使用仓库 `signing/` 中的同一证书；测试版和正式版包名均为 `com.preface.carplay`，可相互覆盖；旧包名应用不自动升级或迁移数据。
3. 从 [GitHub 发布页](https://github.com/milesmou/CarPlay-Preface/releases)下载当前正式版；主 APK 已包含实验性认证资源及授权组件。需要授权组件时，在“设置 → 授权”保存后手动安装或升级至 11，详见 [系统授权](SYSTEM_AUTHORIZATION.md)。
4. 按所用功能授予蓝牙、定位、麦克风和通知权限。车机上的其他投屏应用可能占用同一连接或音频资源，连接前关闭。
5. 首次启动进入居中的单设备主页；自动连接默认开启，实际蓝牙手机连接或 USB 插入时启动，开机自启单独设置。配对和权限按需提示，没有连接向导。

ADB 在线时可覆盖安装并保留数据：

```sh
adb -s <设备序列号> install -r CarPlay-Preface-0.2.0-1202.apk
```

相同包名的旧应用若使用不同证书，覆盖安装会失败；构建流程会报告错误，不自动卸载或清除数据。

## 有线连接

使用支持数据传输的 USB 端口和线缆；自动连接开启时插线启动，否则点击主页 USB 设备行手动连接。按提示授予 USB 和本地 VPN 权限，应用使用 NCM＋仅本应用的本地 TUN，不连接远程 VPN。固件声明 USB host／accessory 能力，但各物理端口是否可连接 iPhone 仍需实车核对。

## 无线连接

点击主页实际在线的手机可手动发起无线连接。进入“设置 → 连接 → 无线连接”，在“热点方式”中选择“临时热点”或“手动车机热点”，默认临时热点。更改方式或热点信息在下一次连接生效，不自动中断当前会话。

临时热点：应用通过 Android `WifiManager.startLocalOnlyHotspot()` 创建本地网络，名称、密码和频段由系统分配，并通过蓝牙传给 iPhone。无需预先填写热点名称和密码。Android 9 需授予定位权限并打开系统定位；车机系统热点已开启时请先关闭，以免系统拒绝临时热点请求。临时热点不提供互联网，手动断开后保留本应用仍有效的预约，重连复核后复用；完全退出或改用 USB／手动热点才释放本应用预约，不关闭其他持有者热点。

手动车机热点：先在车机系统设置中开启并配置热点，选择手动模式后，在连接页面的“热点手动配置”模块中保存完全一致的 SSID 和密码，保留名称和密码中的实际空格。SSID 最长 32 个 UTF-8 字节，受保护热点密码须为 8–63 个字符；仅无密码热点可留空。加密类型应与系统设置一致，密码不能用于推断 WPA3。应用只使用该热点，不修改热点名称或密码，选择手动模式后尝试使用系统保存配置开启热点，不自动关闭它；权限不足或接口不可用时提示原因，需在系统设置中处理。iPhone 连接的就是这个车机热点；手动加入只验证 Wi-Fi 接入，不能代替 CarPlay 会话验证。

iPhone 保持 Wi-Fi 和蓝牙开启并与车机配对，再按需点击主页在线手机。应用检查蓝牙和网络状态，按已保存的模式准备网络并向 iPhone 发送热点配置。不迁移旧热点配置，不提供 Wi-Fi Direct 或同一局域网模式。

若自动加入失败，可手动加入本次生成的热点，再记录是否建立 CarPlay 连接。Android API 或硬件不支持临时热点时显示错误，可使用有线连接。

## USB 授权与诊断

Android 7.1–9 的标准 USB 授权页面确实缺失时，应用只尝试使用已批准的本机 ADB 授予该 iPhone 的 USB 权限；失败后仍保留系统授权请求，不自动打开 ADB 或批准新连接。

在“诊断 → 在手机上取得报告”中，通过二维码或地址和临时验证码打开本地页面下载报告。浏览器空闲连接不会阻塞其他请求；连续输错验证码五次会禁用本次验证码入口。离开页面后本地服务停止，下载前先检查报告内容。

## 音频与方控

默认媒体音频流为 3，导航音频流为 12；音量全部由车机系统控制，已有音频路由设置优先。更改音频路由后按页面提示重新连接。

星瑞方控通过原厂标准媒体广播处理切歌及播放／暂停，原厂音量键继续由车机处理。Siri 支持语音广播及按键学习；电话键已接入短按接听／挂断，原车 HFP 存在或未知时保留原车处理，新增电话键仍待实车验证；不使用其他车型的 OneOS 输入服务。

## 问题反馈

在“诊断”中保存报告，注明星瑞年款、E02 固件、应用版本、iPhone／iOS 版本、连接方式、复现步骤和发生时间。报告应先自行查看再上传，不包含热点密码或配对密钥。请向 [当前仓库](https://github.com/milesmou/CarPlay-Preface/issues) 反馈。
