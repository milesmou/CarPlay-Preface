# CarPlay 快捷操作

连接 CarPlay 后，三指下滑打开居中的快捷面板。上方为媒体和导航音量控制，下方为“返回主界面”“全部设置”“画面调整”“退出应用”四个按钮；宽度不足时按钮自动换行，内容可滚动。点击空白处返回投影，拖动或取消不视为点击。

画面调整只在有效 CarPlay 会话的快捷菜单提供，设置页没有该入口；保留已保存的亮度、对比度、饱和度和色温。仅下次连接生效的设置仍通过设置页提示重新连接。

从快捷菜单“全部设置”打开设置后，设置页返回按钮和系统返回键直接恢复原 CarPlay 投影，不先回主页；备份等子页先回设置，再返回投影。从应用主页进入设置仍返回主页。会话已结束或连接已取消时返回主页，不发起新连接；返回本身不主动重连或应用待重连设置。2026-10-21 源码已调整，尚未打包，验证记录见 [返回导航](CARPLAY_HOME_NAVIGATION.md#从投影进入设置后直接返回投影2026-10-21)。

菜单使用“界面大小”配置，默认星瑞 12.3 英寸的 160 dpi 应用逻辑密度，保留系统字体比例。按钮等高，尺寸、圆角与间距使用统一 dp 常量；菜单缩放不修改协商像素、视频窗口资源或触摸映射。

界面预览固定为 1920×720 横屏；默认参数及完整／紧凑大字体验证见 [屏幕基准](PREFACE_SCREEN_LAYOUT.md)。测试渲染须注明来源，不能作为已安装 APK 或实车截图交付。应用仅支持中文。
