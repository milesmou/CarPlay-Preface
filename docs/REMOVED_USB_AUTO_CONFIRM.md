# 移除 USB 权限自动确认

2026-10-15 按用户要求移除“自动确认 USB 权限”功能，包括设置开关、激活提示、配套授权按钮／弹窗、本地 ADB 自动授权操作、`UsbAutoConfirmService` 及其 manifest／无障碍 XML 配置和专用资源。旧服务不再随 APK 注册，也不再执行自动勾选／点击。

正常 Android USB host 的系统授权、设备归属检查、USB 连接及自动 NCM 诊断保留。系统需要授权时由用户确认，不绕过 USB 权限。没有针对历史无障碍启用列表加入迁移或自动改写，不影响用户其它服务。

可选自定义方控原先复用的通用无障碍设置入口移到 `WheelKeyService`，其原启用／授权行为保留；共享列表锁现在由唯一剩余使用者自行管理。删除的 USB 授权工具不再附带申请悬浮窗／桌面权限。

验证包含已启用旧服务时设置项仍不出现、manifest 不再注册旧服务且保留方控服务、设置分组／翻译及方控授权回归。以 1920×720 横屏、字体 150%，分别使用 mdpi 全窗口和 xhdpi 紧凑窗口生成并核对截图，路径为本地忽略目录 `agent_docs/screenshots/remove-usb-auto-confirm/{full,compact}-font150.png`。没有新增行对齐规则。

本轮没有构建 APK；现有 0.1.1-64 仍包含旧功能，后续新包才包含移除改动。历史上游发布说明保留为历史记录，不代表当前分支继续提供该功能。
