# 无线画面与音乐流畅度

当前 E02 无线只提供临时热点和手动车机热点，见 [热点配置](MANUAL_HOTSPOT.md)。不提供 Wi-Fi Direct、固定信道或旋转方形画布；旧上游其他车型的信道和帧率测试不能当作 E02 推荐值。

按用户 2026-10-20 最新要求，高效视频、直接视频输出和 MTK 解码器低延迟在未保存时默认开启；已保存的选择优先。HEVC 硬件能力检查、MTK 解码路径检查和失败回退保留，普通低延迟与流畅视频仍默认关闭。当前源码及实车反馈范围见 [默认设置与验证记录](PREFACE_WIRELESS_VIDEO_2026-10-20.md)。

## 先区分卡顿来源

| 观察 | 含义与后续检查 |
| --- | --- |
| 接收帧率下降、网络间隙增加 | 检查热点接口、地址、会话和实际网络状态；静止画面也可能少发帧，不能只看一次 maxGap |
| 接收正常、解码／显示落后 | 查看 decoder、输出时序、队列和表面恢复；解码输出数不等于屏幕实际呈现数 |
| 音乐欠载 | 检查音频到包间隔及缓冲；缓冲不能补回实际丢失的数据 |
| 音乐持续越来越晚 | 检查压缩积压和时钟误差，不能无限增加缓冲掩盖问题 |

CarPlay 协商像素只受“隐藏导航栏”控制：1920×720 或 1760×720。临时窗口变化只影响本地显示与触摸映射，不重建连接，见 [分辨率](PREFACE_FIXED_RESOLUTION.md)。

## 播放实现

普通音乐经解码缓冲进入 AudioTrack。音乐时钟补偿计入待解码包时长，真实积压持续后才回收过期包，短暂补包不立即丢弃；导航、电话和语音不进入音乐积压回收或调速路径。当前修正和阈值统一见 [v0.2.21 同步](UPSTREAM_SYNC_0.2.21.md)。

平滑视频实验选项通过 SurfaceView 和本地显示时钟安排输出，利用近期到达与解码延迟调整呈现时间；有额外延迟和画面调整兼容性代价。源码保留不代表 E02 已验证有效。启用前后需在相同连接、画面、分辨率和帧率条件下比较，不根据其他车型的跑分默认开启。

## 取证与验证

记录应用／固件／iOS、连接方式、热点方式、实际协商尺寸和故障时间。结合连续视频统计、音频队列／欠载及焦点日志，区分网络、解码和音源问题；必要时对照系统实际呈现记录。诊断导出见 [安装与反馈](INSTALL.md)。

当前车机预览固定 1920×720 横屏，已安装截图与测试渲染分别标明来源。长期播放、切换前后台、导航／Siri／电话中断、热点复用与重建仍需在实际 E02 验证。
