# 移除“显示（实验性）”卡片

2026-10-15，按用户截图要求移除整个卡片及三个功能：分屏中的 CarPlay、随屏幕旋转 CarPlay 无需重新连接、CarPlay 旁的侧边面板。

## 实现范围

- `SettingsSection.EXPERIMENTAL_DISPLAY`、分类映射、卡片、附属“方形画面”选项及中英文资源一并删除，搜索不再收录。
- 删除分屏窗口记忆、分屏区域声明／切换、旋转方形画面与横竖区域切换；不再读取 `diplay_split_screen`、`diplay_carplay_rotation` 中的旧设置。
- 删除侧边面板视图、拖拽调整、边缘拉出手势、模糊动画、会话菜单按钮和配置读写，不再读取 `diplay_side_panel`。
- `CarPlayViewAreas` 仅保留固定程序栏位置所需的两个完整画面区域，不再有分屏、横竖或侧边面板区域。默认自动程序栏不声明额外区域。

常规显示设置仍保留：分辨率、CarPlay 界面大小、帧率、日夜模式、安全区域、程序栏位置、系统栏与原有窗口缩放。应用仍响应系统给出的可用窗口尺寸；不将所有窗口尺寸变化都强制重连。当前已运行会话不会因设置卡片移除而由应用强制中断。

同日按后续截图要求删除“画中画与分屏自适应”设置项、中英文说明、偏好读写与备份键。窗口比例改变不再通过该选项触发重连，旧的 `adapt_pip_resolution=true` 不生效。保留默认窗口缩放及旋转、系统栏布局变化、原始连接窗口扩大等既有处理；不承诺所有窗口变化均无需重连。显示页 1920×720 横屏、150% 字体的完整与紧凑截图保存在本地 `agent_docs/screenshots/remove-pip-resolution/`。

旧偏好文件可以留在设备上，但没有读取入口；无需迁移、清除应用数据或恢复旧开关。备份现有文件白名单本来就不包含这三个偏好文件，不新增旧配置迁移。

## 验证范围

针对星瑞 E02 的 1920×720 横屏验证：写入三个旧启用开关后，新的连接配置仍保持普通横屏画面、自动程序栏无额外区域；固定程序栏只声明两个覆盖完整画面的区域。验证普通显示设置与会话菜单仍可使用，设置分类和翻译完整。

完整／紧凑实验性页面使用同一 1920×720 像素横屏、150% 字体，通过不同密度验证；截图位于本地忽略目录 `agent_docs/screenshots/remove-experimental-display/`。未要求或运行全量 CI，本轮未构建 APK。

本次范围内 21 项定向测试通过：旧设置与配置 3、固定程序栏区域 2、设置分类／截图 10、资源翻译 1、会话菜单与分辨率／安全区域保留 5。两张截图已视觉核对。

额外扩大到整个 `CarPlayHostSettingsTest` 时，55 项共通过 48、失败 7；失败均为旧热点／USB 测试反射访问不存在的 `hotspotCredentialsView`、`vpnReady` 或 `awaitingVpnConsent`。核对本轮开始时的 HEAD `a9feb2ad`，生产源码已没有这些字段，属于既有测试与实现不一致；没有将该扩大检查描述为全部通过，也没有为修复测试而恢复 VPN／旧热点视图。失败项为两项热点文字测试、两项热点截图和三项 USB 切换／附件测试，后续需单独更新。
