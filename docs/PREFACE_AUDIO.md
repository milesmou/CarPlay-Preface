# 星瑞 E02 方控与音量

CarPlay 媒体和导航音量全部由车机系统音量控制，设置页不再提供应用内音量比例。播放器正常输出保持 100%，不读取旧媒体／导航比例，也不迁移旧设置。通话和音频焦点引起的临时压低、静音及恢复仍保留。

媒体／导航默认音频流为 3／12，已保存的自动或自定义音频路由优先。更改路由按页面提示重新连接。独立流可分别调节；共享流同步变化；自动或创建失败回退的输出按系统 AudioAttributes 的音量流调节，无法查询时使用车机媒体音量，不保证独立调节。

方控按媒体播放状态选流的开关默认启用：媒体播放时调媒体，暂停或未播放时调导航，导航未播报也可预调。实际输出创建后以其路由为准。前台处理标准音量键，后台需要已有无障碍服务；私有方控申请系统拦截，失败时保留原车处理。通话、Siri、原车音源、车载蓝牙、地图缩放与摇杆优先。

固件静态证据来自 IHU519G / FS11A1 / Android 9 / 构建 327，见 [固件分析](PREFACE_FIRMWARE_327.md) 和 [参考索引](PREFACE_FIRMWARE_REFERENCE.md)。系统流编号及原厂音量动作已静态确认；第三方拦截权限、导航／媒体独立音量和实车交接仍待验证，不能据此声称所有星瑞 E02 固件均已验证。
