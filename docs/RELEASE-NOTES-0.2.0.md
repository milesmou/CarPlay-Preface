# CarPlay-Preface 0.2.0

适配 **2023 款吉利星瑞 1.5T（E02）车机，12.3 英寸、1920×720 横屏，无飞屏功能**。

- USB 优先，支持自动连接、临时热点与手动车机热点；有线采用 NCM＋本应用本地 VPN。
- 提供 CarPlay／蓝牙两种音频方案，改进蓝牙音频交接、导航混音和通话后恢复。
- 接入切歌、Siri、电话接听／挂断；电话保留原车 HFP 优先，新增电话键功能仍待实车验证。
- 简化中文主页、设置和快捷菜单，移除独立媒体助手。
- 内置 Android 9 授权组件 11，保存为 `Preface-Android9-Authorization.apk` 后手动安装；旧组件需手动升级。

正式版和测试版统一包名 `com.preface.carplay`，保持仓库原有签名，可相互覆盖。本次构建号 **1202**。旧包名应用不会自动升级或迁移数据，也不会自动卸载。

上游基线：DiPlay v0.2.21（三项选择性同步）。此前构建 100 的实车结果属于旧包；不代表新包名的厂商媒体准入或全部功能已完成实车验收。授权组件仅适用于 API 28、匹配平台证书的系统。
