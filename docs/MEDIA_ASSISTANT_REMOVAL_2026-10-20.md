## 依据与当前行为

IHU353G / Android 9 API 28 / 系统 169 的构建 100 日志确认：授权组件 10 实际断开所选 iPhone 的 A2DP，CarPlay 随后取得音乐焦点，一次无线方向盘 NEXT 成功，退出后无线与 USB 均恢复 A2DP。独立媒体助手已运行且拥有 OEM 权限，但被原车 OpenAPI 明确拒绝 mediacenter，SDK ready=false、注册 token 不存在。因此移除助手，保留已有成功证据的授权组件交接。

当前源码：

- 删除 `media-assistant` 模块及 Gradle 注册，不再构建、签名或校验该独立 APK。
- 删除主应用中的助手身份探测、Messenger IPC、原厂媒体源回退和包可见性声明。
- 媒体中心工厂直接使用主应用自己的 `PrefaceMediaCenterBackend`；继续检查真实 ready、注册 token 与 requestPlay，不伪造厂商准入。
- 主 APK 生成资产任务仅依赖授权组件，只同步 `authorization-components` 的生成资产。原有 Sync 任务会在下次执行时移除输出目录中的旧助手资产。
- “保存授权 APK”只核验并保存 `Preface-Android9-Authorization.apk`，保留固定文件名、校验后覆盖、相同内容去重和独立打开下载目录；说明文案恢复为单个授权组件。
- 删除助手专用安装／导出类、源选择测试、模块测试以及 Python 签名／校验脚本和对应测试；授权组件的固定文件名升级覆盖测试继续保留。
