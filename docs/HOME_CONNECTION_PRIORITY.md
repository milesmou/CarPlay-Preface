# 主页与连接优先级

主页居中显示蓝牙／USB 简短提示和最多一台设备，提示默认字号从 16 sp 增至 18 sp，紧凑窗口保留 16 sp（均随系统字体缩放），取消无线、USB 双卡片。右上角操作组以设置为首项；设置默认进入“连接”，没有连接向导或 Overview。

## 显示与手动连接

设备选择顺序：当前 CarPlay 会话 → 当前 USB 优先设备 → 一台实际在线的蓝牙手机（优先已保存手机）。点击会话返回投影，点击在线手机启动无线。自动连接关闭或本次连接取消后，点击 USB 设备行可手动连接，不增加独立 USB 连接按钮。

蓝牙在线证据来自接收端 A2DP sink（11）、HFP client（16）、可用的普通 profile 和 ACL 事件；已配对列表本身不等于已连接。明确非手机的设备排除，名称不用作手机判断。断开、权限失效和关闭蓝牙会刷新状态，页面离开后释放观察与 proxy；轮询不扫描、配对或主动连接蓝牙。

自动连接默认开启，开机自启独立且默认关闭；事件与启动规则见 [自动连接](AUTOMATIC_CONNECTION.md)。

## USB 优先

- 自动连接开启时，Apple iPhone 插入入口和进程内观察可启动 USB；同一设备的轮询及重复通知不反复拉起，拒绝权限或失败后不循环重试。
- USB 新请求使旧无线启动代际失效；蓝牙唤醒、通知／权限回调及最终投影入口均复核优先级。运行无线时接入 USB，等旧控制器通过清理屏障关闭后再启动有线。
- 有效有线会话始终优先。USB 失败不会自动回退无线，但返回主页后可以明确点击在线手机；旧资源关闭后启动无线，同一线缆的轮询、重复通知和迟到授权不得抢回。
- 无线选择仅针对本进程内这次 USB 接入；重新插拔、不同设备或手动有线重试恢复 USB 优先，旧失败回调不得标记新请求。拔线后不擅自选择另一部手机。

USB 使用 [NCM＋本地 VPN/TUN](USB_VPN_RESTORE_0.2.20.md)，保留 USB、VPN、配置、配对与认证检查。配置切换的重新枚举归现有控制器管理，不因每个插入事件重建会话。

## 返回主页取消

从连接等待页返回主页会中断本次 USB 和无线尝试：使重连任务、排队 Intent、授权回调和旧请求代际失效，并通过已有清理屏障释放控制器。主页轮询、同一线缆重复通知和蓝牙唤醒不能重新启动已取消的尝试。

手动点击设备、重新启用自动连接或 USB 物理重插可以开始新请求。已经运行的投影返回主页时继续保持；本应用仍有效的临时热点预约按 [热点生命周期](MANUAL_HOTSPOT.md) 保留。
