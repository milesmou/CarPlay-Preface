## 应用大小

“界面大小 → 星瑞 12.3 英寸”使用 160 dpi 的应用逻辑密度，使同一块屏幕在系统报告 160／240／320 dpi 时，此模式的控件物理像素大小一致。160 dpi 是应用设计基准，不是对屏幕物理 PPI 或车机系统密度的检测结果。以普通设置行为例，60 dp 对应 60 像素；12.3 英寸、1920×720 的标称尺寸换算后约为 9.1 mm。

选项顺序为：星瑞 12.3 英寸、75%、100%、125%、150%。百分比仍相对系统大小缩放；例如系统 240 dpi 时，75% 使用应用 180 dpi。自动模式及其缩放逻辑已移除，200% 不再提供。

星瑞选项以独立值 `-1` 保存。未设置、保存值不在当前选项中时使用星瑞选项；已有有效百分比选择继续保留。没有旧配置迁移分支或自动模式回退。点击“应用”后刷新本应用界面，点击“取消”不保存。

该设置只影响本应用的首页、设置和裁剪页面，不修改系统显示密度、系统字体设置或 CarPlay 协商像素。有效手动比例保留原有含义，以系统大小为基准；系统大字体仍生效。应用并不根据车型字符串、系统型号或固件号决定是否启用。

上下文覆盖设置密度、语言并保留当前系统字体比例，不固定窗口宽高。字体比例变化后 Activity 重建时重新读取。窗口缩小、系统栏显示或分屏时继续按实际可用 dp 尺寸布局，宽屏分类栏和紧凑分类条按可用空间切换。大字体或较小窗口允许滚动，不截断授权按钮。
