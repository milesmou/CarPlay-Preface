# CarPlay-Preface 0.1.0 预览版

本仓库首个星瑞 E02 适配预览版，基于 **DiPlay v0.2.18**。应用版本 **0.1.0**，versionCode **38**。

**本次附件为签名的源码预览 APK，未包含 CarPlay 配件认证资源。可以安装并测试界面；独立连接 iPhone 需要另行提供并构建认证资源，见 [构建说明](BUILD.md)。APK 发布签名与 CarPlay 配件认证是两种不同的配置。**

## 改动

- 应用名改为 CarPlay，车辆按钮使用星瑞名称和图标，界面固定为简体中文。
- 移除首次设置的车型／DiLink 选择，首次设置缩减为四步。
- 移除概览菜单，设置默认进入连接；实验性功能集中到实验性菜单。
- 移除比亚迪专属方控、HUD／仪表、车辆数据、氛围灯、通话及连接修复代码。
- 针对 `IHU519G / FS11A1 / Android 9 / 构建 327` 接入原厂切歌、播放／暂停广播。广播、MediaSession 和前台窗口共用去重处理；拥有媒体焦点时支持后台切歌，保留原车音量键处理。
- 媒体和导航音量可独立调节，初始值均为 **50%**，已有自定义值继续使用。该固件默认使用媒体流 3、导航流 12。
- 检查更新改为当前 `milesmou/CarPlay-Preface` 仓库；应用版本与上游基线独立维护。
- 保存固件接口、音频、麦克风、连接、定位、视频、权限和电源参考资料，供后续适配复用。

## 验证与限制

- Release Lint、APK 构建及签名校验通过，使用本仓库已有发布密钥；附件同时提供 `SHA256SUMS.txt`。
- 方控相关 63 项测试、音量相关 5 项测试通过，Debug Lint／构建通过。
- 完整 CI **未全通过**：已知热点配置、部分设置页面测试及更新安装兼容性测试仍有失败，不将此次预览描述为完整检查通过。
- 星瑞实车尚未验证。构建 327 的私有编号不直接适用于所有 E02 固件；原厂语音键唤醒 Siri 尚未专门接入，已有通用 Siri 按键功能。
- 在线模拟器已安装其他签名的同包名应用，Release 覆盖安装返回 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`；此前 Debug APK 已安装成功。本次没有卸载应用或清除数据来绕过签名冲突。
- 导航方控、麦克风、USB／Wi-Fi 连接、原车媒体优先和熄火／唤醒行为仍需实车测试。
