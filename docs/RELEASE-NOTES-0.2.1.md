# CarPlay-Preface 0.2.1

适配 **2023 款吉利星瑞 1.5T（E02），12.3 英寸、1920×720 横屏**。

- **视频默认设置**：高效视频（HEVC）、直接视频输出、MTK 解码器低延迟在未保存设置时默认开启，保留用户已保存的选择、硬件能力检查和失败回退。
- **高级设置**：分类“实验性”改为“高级”，普通选项在上、实验功能在下。直接视频输出和 MTK 解码器低延迟去掉实验性标识；普通“低延迟解码”仍保留标识。
- **MTK 显示条件**：按当前 H.264／HEVC 的可用解码路径显示该选项，非 MTK 解码器跳过 MTK 专用参数。

包名保持 `com.preface.carplay`，使用原有签名，构建号 **1204**，可覆盖安装此前正式版及 1203 测试包。主 APK 内置 Android 9 授权组件 **11**，仍由用户在“设置 → 授权”保存后手动安装。

视频默认值、已保存关闭选择、HEVC 回退、MTK 能力判断和界面布局相关 17 项定向验证通过，未运行完整 CI。用户反馈 MTK 低延迟实车测试未见异常；帧率、画质和延迟改善幅度仍待对照测量。

上游基线保持 **DiPlay v0.2.21（三项选择性同步）**。
