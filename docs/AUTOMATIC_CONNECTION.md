# 自动连接与开机自启

自动连接卡片位于“连接”页面第一位，在无线连接、连接状态和 USB 设置之前。

## 两个选项

“设置 → 连接 → 自动连接”只保留：

- **自动连接**：未保存时默认开启，已保存的开关值保留。手机蓝牙连接成功或 USB 插入时，按实际设备发起无线或有线连接。打开主页时也检查实际在线设备，USB 优先；仅配对但没有在线证据的手机不会自动连接。
- **开机自启**：独立控制收到系统 `BOOT_COMPLETED` 后打开应用，默认关闭，保留已保存值。两项都开启时，打开应用后按实际设备连接；只开启自启时停留主页。开关不申请额外权限，也不执行 ADB 授权。

移除打开时连接、独立蓝牙开关、默认连接模式和预选 iPhone 控件。旧模式和独立蓝牙键不再参与行为或设置备份，不添加迁移代码。手机地址仍作为当前连接目标的内部记录，连接事件中的手机可成为新目标；已有会话或正在清理的旧连接不会被另一部手机自动替换。

## 入口与取消

- 蓝牙 ACL 连接／断开由 Manifest receiver 接收；进程内接收端 profile 事件作为补充，ACL 不再重复动态注册。保留权限、非手机类型过滤、当前会话、USB 优先、取消代际和重复事件去重。Android 将 ACL 连接／断开列为 Manifest 隐式广播限制的例外，见[官方广播文档](https://developer.android.com/develop/background-work/background-tasks/broadcasts/broadcast-exceptions)。这不代表车机必定投递广播或允许后台拉起。
- USB 继续使用 NCM＋本地 VPN/TUN。关闭自动连接后，主页轮询、插入事件、系统直接启动 Host 和排队的自动请求不能开始新连接；不主动切断已有会话。
- 关闭自动连接或取消本次连接后，可点击主页 USB 设备行手动连接，不增加独立 USB 连接按钮。在线蓝牙手机仍可手动连接；已有投影和画面设置入口不受自动开关限制。
- 通知／VPN／无线权限结果和旧连接关闭后的回调在启动前复核开关及取消状态。手动“重试”仍有效，权限仍由用户正常授予。
- 从连接等待页返回主页继续取消本次 USB／无线重连，不因默认自动连接开启而拉回。当前进程需明确手动连接、重新启用自动连接或重新插线后开始新请求；旧代际仍失效。有效临时热点预约和原清理屏障保留。

## 验证边界

源码定向检查覆盖两个开关、在线设备选择、USB 优先、取消代际及已有会话保护。开机广播投递、后台打开应用、蓝牙和 USB/TUN 建链仍需对应车机实测；`startActivity()` 返回不等于已显示应用或连接成功。参考固件与运行设备的区别见 [固件资料](PREFACE_FIRMWARE_REFERENCE.md)。
