# CarPlay-Preface

[上游 DiPlay](https://github.com/shihabal3amri/DiPlay)

本仓库基于 DiPlay，主要面向**吉利星瑞车型的 E02 芯片版本车机**进行 CarPlay 适配。

当前开发版本：**0.1.1（尚未发布）**；上游参考：[DiPlay v0.2.20](https://github.com/shihabal3amri/DiPlay/releases/tag/v0.2.20)，按星瑞需求选择性同步，见 [同步记录](docs/UPSTREAM_SYNC_0.2.20.md)。构建 75 另参考 [GeelyPlay v0.2.20.1](https://github.com/huangwits/DiPlay-Preface/releases/tag/v0.2.20.1) 移植蓝牙音频流程，见 [移植范围](docs/GEELYPLAY_BLUETOOTH_0.2.20.1.md)。在 GitHub 正式发布此版本前，所有开发修改与上游同步均保持应用版本号 0.1.1；`versionCode` 保持单调递增，以支持覆盖升级。

[0.1.0 预览版](https://github.com/milesmou/CarPlay-Preface/releases/tag/v0.1.0) · [发布说明](docs/RELEASE-NOTES-0.1.0.md)。附件为签名源码预览 APK，独立连接 iPhone 需另行配置 CarPlay 配件认证资源；实车验证及完整 CI 尚未全部通过。

当前源码已导入上游官方 APK 的两项实验性配件认证资源，主应用构建默认打包，可用于独立连接测试。详见 [认证资源来源与构建方式](docs/CARPLAY_AUTH_RESOURCES.md)，实际 iPhone 和星瑞车机连接仍需验证。

按所有者要求，[APK 签名密钥与签名密码](signing/README.md) 也在仓库公开，克隆后可使用同一证书构建 Release APK。

## 相对上游的改动

- **适配目标与默认配置**：专门面向星瑞 E02，直接默认使用媒体流 3、导航流 12，日常播放增益为 1，用户音量由车机系统控制，并接入方控媒体广播，无需识别车机型号或固件号。构建 76 按已验证 Linkco APK 的播放流程补齐音频优先级：导航播报时将本应用音乐压至 30%，通话／Siri 实际发声时静音音乐，结束后恢复；播放器与媒体方控共用默认启用的音频焦点，保留用户已保存的关闭和路由设置，详见 [音频移植](docs/LINKCO_CARPLAY_AUDIO.md)。Siri 优先使用语音通信麦克风源，失败时尝试语音识别源；本应用的新实现仍需实车验证。
- **星瑞 E02 方控接入**：默认尝试注册车机原厂媒体中心音源，通过回调切歌；接口不可用或注册／播放申请失败时保留原厂媒体广播、MediaSession 和窗口接入，多路径共用去重。原厂切歌独立于音量选流开关，明确区分播放／暂停。默认媒体流 3、导航流 12，保留用户路由设置，原车仍处理的私有音量键保留原车调节。媒体 SDK 按第三方盒子完整链路对照，补齐实例创建顺序、主线程初始化、进程注册复用与稳定播放记录，见 [对照移植](docs/PREFACE_LINKCO_MEDIA_REPLICA.md)。参考固件为 IHU519G／FS11A1 构建 327；新音源接入准入与切歌不跳页仍待实车验证，详见 [原厂媒体中心接入](docs/LINKCO_APK_MEDIA_KEYS_REFERENCE.md)。
- **同步 0.2.20 通用修复**：Android 9 设置搜索、USB 配置与同枚举重连、麦克风空读恢复、音频调度与时钟补偿、无线／USB 独立缓冲、手动热点启动兼容、崩溃及按键诊断；静态与定向测试结果不替代实车验证。详见 [同步记录](docs/UPSTREAM_SYNC_0.2.20.md)。
- **同步 0.2.19 通用优化**：蓝牙启动前检查与适配器获取回退、倒车返回尺寸保持与最后一帧恢复、Android 9 USB 授权页面缺失时通过已授权 ADB 恢复、连接失败提示、手机诊断报告下载及本地页面连接处理；实车效果仍待验证。
- **设置入口精简**：移除“概览”，默认进入“连接”；宽屏左侧分类、窄屏横向分类直接切换设置。
- **12.3 英寸中控屏**：界面大小默认选择“星瑞 12.3 英寸”，以用户确认的 2023 款星瑞 1920×720 横屏为基准，采用统一的应用逻辑密度。另提供 75%、100%、125%、150%，移除自动与 200% 模式，保留有效的百分比设置、系统字体大小和窗口适配；预览提供已安装 APK 的原始截图，详见 [屏幕适配说明](docs/PREFACE_SCREEN_LAYOUT.md)。
- **授权**：设置新增独立分类，顶部提示“请先安装原生设置”，提供“修改系统设置”和“创建 VPN”手动授权入口。修改系统设置显示当前状态；VPN 显示最近一次手动检查结果，取消或缺少系统组件时提示重试。此入口只请求授权，选择 USB 连接时再建立本地 VPN/TUN。详见 [授权说明](docs/SYSTEM_AUTHORIZATION.md)。
- **方控与独立音量**：CarPlay 前台处理标准播放／暂停、上／下一曲，车载蓝牙音频模式避免重复转发；媒体和导航音量全部由车机系统控制。默认媒体播放时方控调媒体音量，暂停或未播放时调导航音量，导航未播报也可预先调节；已保存的关闭设置保留。私有方控申请系统拦截，失败时保留原车行为，标准音量键后台处理需要无障碍服务。其他 E02 固件接口仍需单独确认，尚未实车验证。
- **蓝牙音频交接**：参考 GeelyPlay v0.2.20.1，接入当前 iPhone 的 A2DP sink 代理、真实播放查询、音频归属与退出恢复。蓝牙输出模式保持原车音乐连接、焦点和方控归属；CarPlay 输出模式按焦点归属或手机交接命令移交音乐，仅恢复应用自己断开的且仍配对的设备。音频资源声明与参考版对齐，实车播放后自动暂停是否改善仍待验证；构建 75 未同步 USB，后续构建 82 单独恢复官方 USB/VPN。
- **实验性菜单与名称**：实验性功能集中到“实验性”菜单；应用名改为 CarPlay，车辆按钮默认使用生成的星瑞图标；制造商、型号与 OEM 标签分别默认为“吉利”“星瑞”“Preface”。
- **显示功能精简**：按用户要求删除整个“显示（实验性）”卡片及其分屏区域适配、免重连屏幕旋转和侧边面板功能；旧开关不再生效。CarPlay 分辨率严格由“隐藏导航栏”决定：勾选为 1920×720，不勾选为 1760×720，下次连接生效；分辨率百分比与旧画布缩放不再生效，临时窗口尺寸变化只缩放显示，不重建连接。保留图标文字物理尺寸、帧率、安全区域与程序栏位置，详见 [固定分辨率说明](docs/PREFACE_FIXED_RESOLUTION.md)及[显示功能移除记录](docs/REMOVED_EXPERIMENTAL_DISPLAY.md)。
- **仅保留中文界面**：移除设置页和 CarPlay 内的语言入口，应用固定使用简体中文，不再跟随系统或旧语言偏好。
- **CarPlay 快捷操作**：三指下滑打开与应用配色一致的居中面板，常用操作和音量滑条分组，按钮配小图标、音量读数分列；菜单独立跟随界面大小，保留系统字体，不影响 CarPlay 画面及触摸。点击空白返回 CarPlay，画面调整仍为即时调节入口。详见 [快捷操作界面](docs/QUICK_ACTIONS_UI.md)。
- **简化首页，USB 优先**：顶部提示通过车机蓝牙或 USB 连接 iPhone，设置位于右上角首位；首页只列出实际连接车机蓝牙的手机，点击设备发起无线 CarPlay，不将仅配对的设备当作已连接。USB 区域不再放连接按钮，插入 iPhone 自动连接；接入 USB 时优先切换有线，并拦截迟到的无线请求、权限回调和蓝牙自动连接。重复观察同一线缆不反复拉起，失败后可重新插拔或手动重试。蓝牙状态、设备列表、大字体和紧凑页面按 1920×720 横屏验证，实际车机接入仍待实测。详见 [主页与连接优先级](docs/HOME_CONNECTION_PRIORITY.md)。
- **USB NCM＋本地 VPN**：构建 82 按用户要求恢复官方 DiPlay v0.2.20 的 USB 方案，系统授权后由应用直接接管 iPhone NCM，将 IPv6 帧桥接到本地 TUN，再由 Android TCP/IP 承载 AirPlay。不依赖 root 或系统提前创建的 NCM 网卡；仅允许本应用、仅路由链路本地 IPv6，无远程 VPN 服务器。授权页缺失、拒绝或桥接失败时明确停止并提示处理，无线连接不使用 VPN。详见 [恢复范围与验证边界](docs/USB_VPN_RESTORE_0.2.20.md)。
- **USB 诊断范围**：保留 USB 配置、配对、认证、NCM 端点与阶段耗时日志。旧系统网卡连接及失败后的独立帧测试不再作为当前主流程，避免与实时 NCM/VPN 争抢接口；[旧帧诊断文档](docs/USB_NCM_FRAME_DIAGNOSTICS.md)保留为历史证据。完整 USB 音视频、Siri、拔线重连仍待实车验证。
- **选择 iPhone 弹窗**：使用应用配色与大尺寸按钮，标记已选设备，同名设备显示蓝牙地址末尾以便区分。列表可滚动，配对与取消操作固定在底部；蓝牙关闭、尚未配对时提供系统蓝牙设置入口。已定向验证 1920×720 横屏、大字体、高密度、明暗主题与阿拉伯语 RTL 测试布局，实际车机显示待复测。
- **无线连接方式**：在“设置 → 连接 → 无线连接”卡片中首先显示“手动车机热点（推荐）”，其次为“临时热点”；推荐标记不改变已保存的选择，未配置时默认临时热点。临时热点由 Android `LocalOnlyHotspot` API 创建，名称与密码由系统生成；选择手动模式后，应用尝试用系统保存的配置开启车机热点，同一卡片提供 SSID／密码配置，不再显示独立的“热点手动配置”卡片或“开启车机热点”“打开车机热点设置”按钮。应用不修改系统热点配置或自动关闭热点，CarPlay 会话运行时不操作热点开关。更改在下一次连接生效，首页保持现有连接入口。移除 Wi-Fi Direct 和现有 Wi-Fi／同一局域网模式，不保留旧配置迁移逻辑；两种模式均待星瑞 E02 实车验证。
- **移除比亚迪专属适配**：HUD 与仪表导航、DiLink 仪表显示及任务路由、电池／车速／挡位／胎压读取、氛围灯、专用通话卡片与按键码、蓝牙暂停、Wi-Fi 扫描暂停及开机启动修复。
- **清理其他平台与旧代码**：移除 OneOS 吉利／领克方控 Binder、FCE 仪表导航、哈曼全屏模式、电动车电量与充电接口上报及未使用文案；地图使用通用窗口安全区和尺寸，不套用比亚迪仪表校准。
- **保留通用功能**：有线／无线 CarPlay、Android 位置共享、媒体与 Siri、方向盘按键学习、CarPlay 主屏地图与桌面导航提示。按用户要求移除“仪表盘上的 CarPlay 地图”、独立 Stream 111、桌面地图悬浮卡片及第三方桌面实时地图共享；旧设置不会重新启用该功能。这些代码改动不代表已经完成星瑞 E02 实车兼容性验证。
