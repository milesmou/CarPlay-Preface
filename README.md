# CarPlay-Preface

基于 [DiPlay](https://github.com/shihabal3amri/DiPlay)，适配 **2023 款吉利星瑞 1.5T（E02）车机**，**无飞屏功能**。

应用版本：**0.2.2（构建 1210，测试版）**；最近正式发布版本为 **0.2.1（构建 1204）**。正式版和测试版统一包名：`com.preface.carplay`，使用相同签名，可相互覆盖。上游基线：**DiPlay v0.2.21（选择性同步）**。

## 相对上游的主要改动

- **星瑞屏幕**：默认适配 12.3 英寸、1920×720 横屏，保留界面大小调节。
- **连接**：USB 优先，支持自动连接、临时热点和手动车机热点；USB 使用 NCM＋本地 VPN。
- **音频**：提供 CarPlay／蓝牙两种方案，调整蓝牙交接、导航混音及通话后恢复。
- **方控**：接入切歌、Siri 和电话接听／挂断，保留原车音量与 HFP 电话处理。
- **授权**：主 APK 内置 Android 9 授权组件，保存到下载目录后手动安装。
- **界面与精简**：仅保留中文，简化首页、分类设置和投影快捷菜单，移除其他车型专属适配。

构建 1209 将“仪表导航提示”作为导航页第一项，移除实验性标志，未保存时默认开启，已保存的关闭选择优先，设置变更在下次连接生效；关于页保留免费开源说明和 GitHub 仓库链接。“CarPlay 通话使用车机电话音频”作为普通高级选项，未保存时默认开启，仅在当前会话采用 CarPlay 音频时请求辅助通话，保留已保存的选择。相关说明见 [仪表导航](docs/PREFACE_INSTRUMENT_NAVIGATION_2026-10-27.md)、[电话音频](docs/PREFACE_PHONE_AUDIO_TELECOM_2026-10-21.md)。

仪表导航修正已打入 1209 测试包：按原厂仪表 SDK 的连接、导航更新和停止流程接入，移除 1208 中因缺失 `sys.bicv` 状态属性而阻止发送的额外门槛。原厂 SDK 在实际 169 固件上的输出、权限、准备状态及车机仪表显示仍待实车复测，详见 [10-27 分析与修正](docs/PREFACE_INSTRUMENT_NAVIGATION_2026-10-27.md)。

## 常见问题

1. **CarPlay 音频模式无法切歌**

   请进入 **设置 → 授权**，点击“保存授权 APK”，通过文件管理器手动安装或更新授权组件，然后重新连接 CarPlay。

2. **有线连接失败**

   请在 **设置 → 授权** 页面保存并手动安装或更新授权组件，再返回该页面点击 **创建 VPN**，按系统提示允许授权，然后重试有线连接。
