# CarPlay-Preface

[上游 DiPlay](https://github.com/shihabal3amri/DiPlay)

本仓库基于 DiPlay，主要面向**吉利星瑞车型的 E02 芯片版本车机**进行 CarPlay 适配。

当前开发版本：**0.1.1（尚未发布）**；上游参考：[DiPlay v0.2.19](https://github.com/shihabal3amri/DiPlay/releases/tag/v0.2.19)，按星瑞需求选择性同步，见 [同步记录](docs/UPSTREAM_SYNC_0.2.19.md)。在 GitHub 正式发布此版本前，所有开发修改与上游同步均保持应用版本号 0.1.1；`versionCode` 保持单调递增，以支持覆盖升级。

[0.1.0 预览版](https://github.com/milesmou/CarPlay-Preface/releases/tag/v0.1.0) · [发布说明](docs/RELEASE-NOTES-0.1.0.md)。附件为签名源码预览 APK，独立连接 iPhone 需另行配置 CarPlay 配件认证资源；实车验证及完整 CI 尚未全部通过。

当前源码已导入上游官方 APK 的两项实验性配件认证资源，主应用构建默认打包，可用于独立连接测试。详见 [认证资源来源与构建方式](docs/CARPLAY_AUTH_RESOURCES.md)，实际 iPhone 和星瑞车机连接仍需验证。

按所有者要求，[APK 签名密钥与签名密码](signing/README.md) 也在仓库公开，克隆后可使用同一证书构建 Release APK。

## 相对上游的改动

- **适配目标与默认配置**：专门面向星瑞 E02，直接默认使用媒体流 3、导航流 12，导航与媒体不额外衰减，音量全部由车机系统控制，并接入方控媒体广播，无需识别车机型号或固件号。Siri 优先使用语音通信麦克风源，失败时尝试语音识别源；用户已保存的设置继续优先，实车效果仍待验证。
- **固件 327 方控接入**：根据星瑞 IHU519G／FS11A1 固件分析，接收原厂媒体按键广播，实现上／下一曲及播放／暂停；广播、MediaSession 和前台窗口共用去重处理，支持拥有媒体焦点时后台切歌。该固件默认使用媒体流 3、导航流 12，保留用户路由设置，方控音量按媒体播放状态选流，拦截失败时保留原车处理。详见 [固件分析](docs/PREFACE_FIRMWARE_327.md)，仍待实车验证。
- **同步 0.2.19 通用优化**：蓝牙启动前检查与适配器获取回退、倒车返回尺寸保持与最后一帧恢复、Android 9 USB 授权页面缺失时通过已授权 ADB 恢复、连接失败提示、手机诊断报告下载及本地页面连接处理；实车效果仍待验证。
- **设置入口精简**：移除“概览”，默认进入“连接”；宽屏左侧分类、窄屏横向分类直接切换设置。
- **方控与独立音量**：CarPlay 前台处理标准播放／暂停、上／下一曲，车载蓝牙音频模式避免重复转发；媒体和导航音量全部由车机系统控制。默认媒体播放时方控调媒体音量，暂停或未播放时调导航音量，导航未播报也可预先调节；已保存的关闭设置保留。私有方控申请系统拦截，失败时保留原车行为，标准音量键后台处理需要无障碍服务。其他 E02 固件接口仍需单独确认，尚未实车验证。
- **实验性菜单与名称**：实验性功能集中到“实验性”菜单；应用名改为 CarPlay，车辆按钮默认使用生成的星瑞图标和“星瑞”名称。
- **仅保留中文界面**：移除设置页和 CarPlay 内的语言入口，应用固定使用简体中文，不再跟随系统或旧语言偏好。
- **直接从首页连接**：首页提供无线与 USB 连接操作，配对和权限按需提示，不再显示首次连接向导。
- **USB 系统网卡直连，无需 VPN/root**：使用可确认属于当前 iPhone 的系统 NCM 网卡，由普通 socket 服务承载 AirPlay，不申请 VPN 授权、不建立 TUN 或回退 VPN。网卡不可用、监听失败或启动会话超时时明确报错并停止自动重试。系统驱动支持和真实音视频仍待星瑞 E02 实车验证；没有系统 NCM 网卡时尚无应用内协议栈替代路径。
- **无线连接方式**：在“设置 → 连接”中选择“临时热点”或“手动车机热点”，默认临时热点。临时热点由 Android `LocalOnlyHotspot` API 创建，名称与密码由系统生成；手动模式在车机系统中开启热点，并在“热点手动配置”保存完全一致的 SSID 和密码，应用不自动开启或关闭该热点。更改在下一次连接生效，首页保持现有连接入口。移除 Wi-Fi Direct 和现有 Wi-Fi／同一局域网模式，不保留旧配置迁移逻辑；两种模式均待星瑞 E02 实车验证。
- **移除比亚迪专属适配**：HUD 与仪表导航、DiLink 仪表显示及任务路由、电池／车速／挡位／胎压读取、氛围灯、专用通话卡片与按键码、蓝牙暂停、Wi-Fi 扫描暂停及开机启动修复。
- **清理其他平台与旧代码**：移除 OneOS 吉利／领克方控 Binder、FCE 仪表导航、哈曼全屏模式、电动车电量与充电接口上报及未使用文案；地图使用通用窗口安全区和尺寸，不套用比亚迪仪表校准。
- **保留通用功能**：有线／无线 CarPlay、Android 位置共享、媒体与 Siri、方向盘按键学习、桌面／中控地图。这些代码改动不代表已经完成星瑞 E02 实车兼容性验证。
